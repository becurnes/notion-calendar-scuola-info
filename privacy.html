Informativa sulla privacy

Notion Calendar Scuola è un’integrazione per uso personale. Legge gli impegni selezionati in un database Notion e crea, aggiorna o elimina gli eventi corrispondenti nel calendario Google dedicato dell’utente.

I dati trattati comprendono titolo, data e altre informazioni sugli impegni presenti nel database. L’elaborazione avviene tramite Notion, Google Calendar e GitHub Actions. Le credenziali sono conservate nei segreti di GitHub Actions e non sono pubblicate nel codice.

L’accesso Google può essere revocato dalle impostazioni di sicurezza dell’account Google. Per interrompere la sincronizzazione è possibile disattivare il workflow GitHub Actions e revocare l’accesso all’integrazione Notion.
